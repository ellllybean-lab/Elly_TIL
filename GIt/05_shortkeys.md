## 📝 1. 편집 기본

VS Code 편집기에 커서가 있을 때 사용.

| 단축키 | 기능 |
|---|---|
| `Ctrl + S` | 현재 파일 저장 |
| `Ctrl + Shift + S` | 다른 이름으로 저장 |
| `Ctrl + Z` | 실행 취소 |
| `Ctrl + Y` | 다시 실행 |
| `Ctrl + C` | 복사 |
| `Ctrl + X` | 잘라내기 |
| `Ctrl + V` | 붙여넣기 |
| `Ctrl + A` | 전체 선택 |

=> 수정한 파일은 저장한 뒤 실행하거나 Git에 추가하기

## 📂 2. 파일과 화면 이동

| 단축키 | 기능 |
|---|---|
| `Ctrl + P` | 파일 이름으로 빠르게 열기 |
| `Ctrl + Shift + P` | 명령 팔레트 열기 |
| `Ctrl + B` | 사이드바 표시·숨기기 |
| `Ctrl + Shift + E` | 파일 탐색기로 이동 |
| `Ctrl + Shift + G` | 소스 제어 화면으로 이동 |
| `Ctrl + Tab` | 최근 사용한 편집기 전환 |
| `Ctrl + W` | 현재 편집기 닫기 |
| `Ctrl + \` | 편집기 나누기 |

=> 단축키가 기억 안 나면 명령 팔레트에서 기능 이름 검색하기

## 🔎 3. 검색과 바꾸기

| 단축키 | 기능 |
|---|---|
| `Ctrl + F` | 현재 파일에서 검색 |
| `Ctrl + H` | 현재 파일에서 찾아 바꾸기 |
| `Ctrl + Shift + F` | 프로젝트 전체에서 검색 |
| `Ctrl + Shift + H` | 프로젝트 전체에서 찾아 바꾸기 |

=> 전체 바꾸기를 누르기 전 검색 결과와 대상 폴더 확인하기

## ✂️ 4. 코드 편집

| 단축키 | 기능 |
|---|---|
| `Ctrl + /` | 줄 주석 처리·해제 |
| `Alt + ↑ / ↓` | 현재 줄 위·아래로 이동 |
| `Shift + Alt + ↑ / ↓` | 현재 줄 위·아래로 복제 |
| `Ctrl + Shift + K` | 현재 줄 삭제 |
| `Ctrl + Enter` | 아래에 새 줄 삽입 |
| `Ctrl + Shift + Enter` | 위에 새 줄 삽입 |
| `Ctrl + D` | 다음 일치 항목 추가 선택 |
| `Ctrl + Shift + L` | 현재 선택 내용과 일치하는 항목 모두 선택 |
| `Shift + Alt + F` | 문서 서식 정리 |

=> 서식 정리는 파일 종류에 맞는 포맷터가 필요할 수 있음

## 🎀 5. Markdown 작성

| 단축키 | 기능 |
|---|---|
| `Ctrl + Shift + V` | Markdown 미리보기 열기 |
| `Ctrl + K` → `V` | 옆 화면에 미리보기 열기 |

=> Ctrl+K를 누른 다음 V를 차례로 입력  
=> 왼쪽에서 작성하고 오른쪽에서 모양 확인하기

## 🖥️ 6. VS Code 터미널

| 단축키 | 기능 |
|---|---|
| ``Ctrl + ` `` | 터미널 표시·숨기기 |
| ``Ctrl + Shift + ` `` | 새 터미널 생성 |
| `Ctrl + J` | 아래 패널 표시·숨기기 |

=> ` 문자는 작은따옴표가 아니라 보통 숫자 1 왼쪽에 있는 백틱  
=> 터미널 숨기기는 실행 중인 프로그램 종료와 다름

## 🐚 7. Bash 입력

터미널의 Bash 입력줄에서 사용.

| 단축키 | 기능 |
|---|---|
| `↑ / ↓` | 이전·다음 명령 불러오기 |
| `Tab` | 파일명·명령어 자동 완성 |
| `Ctrl + R` | 명령어 기록 역방향 검색 |
| `Ctrl + A` | 입력줄 맨 앞으로 이동 |
| `Ctrl + E` | 입력줄 맨 뒤로 이동 |
| `Ctrl + U` | 커서 앞에서 줄 시작까지 지우기 |
| `Ctrl + K` | 커서부터 줄 끝까지 지우기 |
| `Ctrl + W` | 커서 앞 단어 지우기 |
| `Ctrl + L` | 화면 정리 |
| `Ctrl + C` | 현재 입력 취소 또는 실행 중인 명령 중단 |

=> Ctrl+C로 모든 작업을 되돌리는 것은 아님  
=> 프로그램에 따라 동작이 달라질 수 있음

## 🩹 8. 헷갈리지 않기

| 상황 | 기억할 것 |
|---|---|
| 편집기의 Ctrl+C | 복사 |
| 터미널의 Ctrl+C | 보통 실행 중단. 선택된 글이 있으면 복사로 동작할 수도 있음 |
| Markdown 파일 | 저장 후 미리보기로 확인 |
| END가 나온 기록 화면 | 영문 q로 빠져나오기 |
| psql에서 나오기 | `\q` 입력 |
| 단축키가 다르게 동작 | 현재 커서 위치와 키 설정 확인 |

=> Windows 기본 설정 기준이며 확장프로그램이나 사용자 설정으로 바뀔 수 있음
